
# ResearchMate AI

An Agentic AI-powered research assistant that transforms research papers into summaries, key concepts, presentations, and viva questions.

## Features
- Research paper summarization
- Key concept extraction
- PowerPoint generation
- Viva question generation
- Chat with research papers

## Technologies
- Python
- Streamlit
- Gemini API
- LangChain
- ChromaDB
- RAG
